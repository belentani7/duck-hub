# Ficha de entidad — Duck

## Identidad de trabajo

| Campo | Estado | Valor / nota |
|---|---|---|
| Nombre operativo | Verificado por el corpus | Duck |
| Actividad | Verificada por requisitos del producto | Productor musical, servicios de producción y catálogo de beats |
| Ubicación operativa | Declarada en el contexto | Recife, Brasil |
| Forma jurídica | No verificada | Debe confirmar si opera como persona física, MEI, empresa u otra estructura |
| CNPJ/CPF | No recopilado | No debe incluirse en repositorio ni chat; pedirlo solo por canal seguro si es necesario |
| Residencia fiscal | No verificada | No asumir por ubicación operativa |
| Moneda de operación | Supuesto de modelado | EUR y BRL; confirmar precios, cobros y cuentas |
| Clientes activos | No verificado | El dashboard tiene el campo, pero no se usa como dato financiero histórico |
| Ingresos históricos | No disponibles | El modelo financiero usa supuestos editables, no cifras reales |
| Propiedad del código | No verificada | Requiere inventario de autores, repositorios, commits y acuerdos |
| Propiedad del catálogo | No verificada | Cada beat debe tener hoja de derechos y titularidad |
| Marca registrada | No verificada | Buscar en INPI y, si corresponde, EUIPO/registro nacional |

## Uso

Esta ficha impide tratar a Duck como una empresa pública o como una entidad fiscal ya constituida. Todo número del modelo debe reemplazarse por datos financieros reales cuando estén disponibles y con fecha de corte.

## Próximos datos seguros

Se necesitan, por canal seguro y con minimización: forma jurídica, jurisdicción fiscal, ingresos cobrados de los últimos meses, costes directos, caja disponible, número de clientes, concentración, titulares del catálogo y situación de la marca. No se deben importar tokens, contraseñas, datos bancarios completos ni conversaciones privadas.
